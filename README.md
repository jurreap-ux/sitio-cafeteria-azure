# Aroma & Grano - Café de Especialidad

Sitio web empresarial desarrollado con HTML5 y CSS3 para el despliegue en Microsoft Azure App Services.

## Integrante
- Jimmy Alexander Urrea Pazmiño

## Objetivo del Proyecto
Diseñar y publicar un sitio web informativo, adaptable (responsive) y estructurado semánticamente para una cafetería de especialidad y tostaduría artesanal.

## Estructura del Sitio
- **Inicio (`index.html`):** Banner principal y productos destacados.
- **Nosotros (`nosotros.html`):** Historia, misión, visión y valores.
- **Menú (`productos.html`):** Catálogo de productos con tarjetas descriptivas y precios.
- **Contacto (`contacto.html`):** Información de contacto y formulario visual.
